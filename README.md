##  Features

- **Premium Dark Aesthetic:** Clean, iOS-style minimal layout with fluid interactions.
- **Bilingual Support (Localization):** Smooth toggle between English (ENG) and Burmese (MM) languages.
- **Responsive Architecture:** Fully optimized for mobile, tablet, and desktop viewports.
- **Theme Controls:** Seamless single-click theme switcher for light and dark modes.
- **Secure Contact System:** Robust API routes integrating with **Resend** for stylized HTML inbox delivery.
- **Smooth Animations:** Built using Framer Motion for high-fidelity interactive elements.

---

##  Tech Stack

- **Framework:** Next.js  (App Router)
- **Library:** React 
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Email Service:** Resend API
